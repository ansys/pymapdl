Report
======

The :class:`ansys.mapdl.core.Report` class creates a report describing the
PyMAPDL installation, optional dependencies, Ansys environment, and available
graphics hardware. The class uses ``ansys-tools-report`` when it is installed
and falls back to a plain-text report otherwise.
